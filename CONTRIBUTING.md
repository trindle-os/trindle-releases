# Contributing

Thank you for your interest in Trindle. This repository holds the release
files for Trindle and its plugins: the signed catalogue and the packages.

## Reporting a problem

If a package does not install or behave as described, open an issue. Please
include the version, your system, what you did, what you expected, and what
happened.

Security problems go to hello@trindle.org, not to public issues. See
[SECURITY.md](SECURITY.md).

## Source code

The source code is not in this repository, so changes to Trindle itself are
not taken here. If you would like a change, describe it in an issue. You are
free to fork any part of Trindle under the licence it carries.
